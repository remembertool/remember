Stochastic process mining

Check how well event logs fit a learned model

REMEMBER learns a Variable-Length Markov Chain (VLMC) from a reference log and scores other logs against it. The main score is uEMSC; three more measures help you read it.

{% if preprint_url %} Tool preprint {% else %} Tool preprintsoon {% endif %}
1
InputA reference log and the logs to check
2
LearningA VLMC is learned from the reference log
3
CheckEach log is scored against the VLMC
4
ReportuEMSC and three supporting measures
Note: the logs to check are only scored. They are never used to learn the model.
Step 1 · Setup

Choose what to run

Your own logs, a small example, or a benchmark from the paper.

Column and attribute namesoptional

Only needed if your logs use other names; empty fields keep the defaults. XES: attribute keys (the case id comes from the trace, or from each event if the trace has none). CSV: column names (found automatically when empty). The names apply to every uploaded log; TXT logs ignore them.

ⓘSettings: none to choose. The VLMC is learned without pruning, as in the paper.
Formats: XES, CSV and TXT, also gzipped (.gz). Events are ordered by timestamp; without one, the file order is kept.

Paper benchmarks

Rerun the experiments of the paper

Pick a dataset. REMEMBER runs the 10 splits of the paper: for each, it learns a VLMC from one half of the log and scores the other half. Your result is then compared with the VLMC and the 8 other techniques in the paper.
